## Info 
I created this homepage using React and Tailwind CSS. The project is currently a static website, so the functionality is not implemented yet, but the UI design is complete.

## Steps 
To run the project on your local machine:

1. Clone the repository:
   git clone "https://github.com/balajilaygude/Bot-League.git"

2. Install dependencies:
   npm install

3. Start the development server:
   npm run dev

After that, open the local URL shown in the terminal to view the project in your browser.
